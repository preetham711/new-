# Preetham - Premium UI/UX Designer Portfolio

A world-class, modern, and interactive portfolio website for Preetham, a UI/UX Designer and Product Designer. Built with React, Vite, Tailwind CSS, and Framer Motion.

## 🎨 Features

### Design
- **Modern & Premium UI** - Award-winning design inspired by Awwwards, Behance, and Dribbble
- **White & Blue Color Palette** - Clean, professional, and elegant
- **Glassmorphism Effects** - Modern frosted glass design elements
- **Smooth Animations** - Framer Motion animations throughout
- **Fully Responsive** - Mobile-first design approach
- **Dark Mode Support** - Toggle between light and dark themes

### Sections
1. **Hero Section** - Eye-catching introduction with floating elements
2. **About Section** - Personal introduction with statistics
3. **Skills Section** - Design and development skills with proficiency bars
4. **Projects Section** - Filterable project showcase with 6 featured projects
5. **Design Process Section** - 6-step design methodology timeline
6. **Experience Section** - Professional timeline with achievements
7. **Testimonials Section** - Client reviews and ratings
8. **Contact Section** - Contact form and social links
9. **Footer** - Navigation and social links

### Advanced Features
- ✨ Scroll Progress Indicator
- 🔝 Back to Top Button
- 🎯 Smooth Scroll Navigation
- 📊 Animated Counters
- 🎬 Page Transitions
- 🖱️ Custom Cursor Effects
- ♿ Accessibility Friendly
- ⚡ Fast Performance
- 🔍 SEO Optimized

## 🚀 Tech Stack

## 📦 Installation

1. Navigate to the project directory:
```bash
cd preetham-portfolio
```

2. Install dependencies:
```bash
npm install
```

3. Start the development server:
```bash
npm run dev
```

4. Open your browser and visit `http://localhost:3000`

## 🎯 Customization

### Colors
Edit `tailwind.config.js` to customize the color palette:
```javascript
colors: {
  primary: '#2563EB',
  secondary: '#3B82F6',
  // ... other colors
}
```

### Content
Update component content directly in the component files:
- Hero section text in `Hero.jsx`
- Projects in `Projects.jsx`
- Experience in `Experience.jsx`
- Testimonials in `Testimonials.jsx`

### Images
Replace emoji placeholders with actual images:
- Update profile image in `Hero.jsx`
- Add project images in `Projects.jsx`
- Add testimonial avatars in `Testimonials.jsx`

## 🚀 Build for Production
